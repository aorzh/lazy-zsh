# lazy-zsh

Switch from bash to zsh + oh-my-zsh with one script, without losing your history and aliases. Changed your mind? One more script brings bash back.

Made and used on Kubuntu. It should work on Debian, Ubuntu and their derivatives (it uses apt). On other distros, install zsh, git, curl, python3 and fzf yourself first, and the script will use them.

## Quick start

```bash
git clone https://github.com/aorzh/lazy-zsh.git
cd lazy-zsh
./install.sh --chsh
```

`--chsh` makes zsh your default login shell (it runs `chsh -s $(command -v zsh)` and asks for your password).

Then log out of your desktop session and log back in. Closing the terminal is not enough: the default shell is picked up at login.

Without `--chsh` your default shell stays as it is, and you can start zsh only in the terminal you want. For WezTerm: `config.default_prog = { '/usr/bin/zsh', '-l' }`.

The last lines of the output tell you in bold what to do next: log out and back in after `--chsh`, or how to start zsh if your default shell is still bash. They also warn you if some terminal starts bash explicitly.

## What install.sh does

- **Packages.** Installs zsh, git, curl, fzf and python3 if they are missing.
- **oh-my-zsh.** Default robbyrussell theme, plus zsh-autosuggestions, zsh-syntax-highlighting and zsh-completions.
- **Plugins.** git, gh, docker, docker-compose, kubectl, rust, python, uv, npm, aws and terraform. Each one is enabled only if the tool itself is installed.
- **History.** Imports `~/.bash_history`, keeping timestamps if bash had them. zsh stores its history file in its own encoding, so a plain copy breaks Cyrillic and other non-ASCII text; the import converts it properly.
- **History settings.** 100k entries, start time and duration for each command, no duplicates. Commands starting with a space are not saved, which is handy for tokens and passwords.
- **Aliases.** `~/.bash_aliases` is loaded as is, and aliases written directly in `~/.bashrc` are copied to `~/.zsh_aliases`.
- **PATH.** zsh does not read `~/.profile`, so `~/.zprofile` loads it. Without this, `~/.local/bin` and cargo can disappear from PATH after the switch.
- **Report of manual steps.** Compares your `~/.bashrc` with the distro default (`/etc/skel/.bashrc`) and lists only what you added yourself: functions, PATH changes, bash-specific init lines and so on, each with a hint. It also finds terminals that start bash explicitly (WezTerm, Konsole, VS Code and its forks). The report is saved to `~/.local/state/lazy-zsh/manual-steps.txt`.

Re-running is safe: files are backed up with a timestamp, plugins get updated, and history is imported only once.

## Your own settings

`~/.zshrc` is regenerated on every run (the old one is backed up). Put your own PATH, functions and exports into `~/.zshrc.local`: it is loaded at the end and never touched.

## Rollback

```bash
./rollback.sh                   # shows the plan and asks before doing anything
./rollback.sh -y                # no questions
./rollback.sh --keep-packages   # do not apt-remove the packages install.sh installed
```

It switches the default shell back, restores your original zsh files if you had any (or removes the generated ones), removes oh-my-zsh with its plugins and copies the commands you typed in zsh back to `~/.bash_history`.

It also apt-removes the packages that install.sh installed. Only those that were not on the system before install.sh are removed: if you already had git or curl, they stay. Use `--keep-packages` to keep them all.

Nothing in your home is deleted: removed files go to `~/lazy-zsh-rollback-<timestamp>/`, remove that folder when you are sure. Terminal settings that start zsh explicitly are not changed; the script lists them so you can change them by hand. After rollback, log out and back in.

## Files

| File | What it is |
| ------ | ------------ |
| `~/.zshrc` | generated by install.sh |
| `~/.zshrc.local` | yours, never touched |
| `~/.zsh_aliases` | aliases copied from `~/.bashrc` |
| `~/.zprofile` | two lines added to load `~/.profile` |
| `~/.local/state/lazy-zsh/` | install record for rollback, manual steps report |
